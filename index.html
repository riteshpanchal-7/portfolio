I turn messy files into clear numbers

Start with the business question, write the query, then chart the one number that answers it.

-- avg days from application to disbursement
SELECT DATE_TRUNC('month', closed_at) AS month,
       AVG(closed_at - received_at) AS avg_days_to_close
FROM   loan_files
WHERE  status = 'DISBURSED'
GROUP BY 1 ORDER BY 1;
